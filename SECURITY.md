# Security

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/krabiclaw/krabiclaw/security/advisories/new).
Do not open a public issue.

Include the affected URL or code path, how to reproduce it, and what an attacker
gains. Test only against your own KrabiClaw organization; do not access other
tenants' data, send messages to real guests, or make payments you do not own.

Fixes ship from `staging` to production continuously, so there are no supported
older versions.
