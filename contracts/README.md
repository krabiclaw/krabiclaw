# Contracts

These files are the JSON the KrabiClaw server returns to its clients, generated by the server's own code rather than written by hand: `contracts/inbox` is the guest inbox (`list.json` from `GET /api/dashboard/guest-threads`, `thread.json` from `GET …/guest-threads/{id}` and every `…/operations/{action}`, `details.json` from `GET …/guest-threads/{id}/details`, `suggestions.json` from `POST …/guest-threads/{id}/suggested-reply`), produced by `tests/contracts/inbox-contracts.test.ts` over one Airbnb stay conversation that holds every stream item type, with a fixed clock and fixed ids. The web dashboard and the iOS app (krabiclaw/krabiclaw-ios-app) decode these shapes. `yarn contracts` runs in CI's Checks and fails when the view model returns anything other than what is committed here; `yarn contracts:write` rewrites the files, so every change to the shape shows up as a diff in its pull request. Adding a field is safe; removing or renaming one, or changing its type, breaks iOS builds already in TestFlight and in the App Store, so it needs the iOS app updated and released first.
